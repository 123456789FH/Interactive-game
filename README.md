# مغامرة كنز القيمة المنزلية — V2.1

لعبة عربية تفاعلية للصف الثالث الابتدائي.

## ما الجديد في V2.1
- صقل الواجهة بحيث تبقى الإطارات والأزرار الأصلية من الرسم ظاهرة بدون مستطيلات إضافية.
- إزالة الغطاء البني فوق صندوق الكنز واستبداله بتوهج وشرارات شفافة.
- ضبط أدق لخانات العدد المطلوب، العدد المبني، العدادات، ومناطق إسقاط الأبواب.
- إضافة حركة انتقال نموذج القيمة المنزلية من البطاقة إلى الباب الصحيح.
- عرض قيمة النموذج أثناء السحب بالأرقام العربية.
- ضبط مناطق النقر والسحب على واجهة اللعبة.
- الأرقام العربية ٠١٢٣٤٥٦٧٨٩ في جميع القيم الديناميكية.
- السحب والإفلات بالماوس واللمس والقلم + بديل بالنقر.
- إمكانية تقليل نموذج واحد بالضغط على عداد المنزلة.
- حركة فتح صندوق الكنز مع توهج واحتفال.
- المستوى ١: بناء العدد بنماذج القيمة المنزلية.
- المستوى ٢: الصيغة القياسية.
- المستوى ٣: الصيغة التحليلية.
- المستوى ٤: الصيغة اللفظية.
- المستوى ٥: تحدٍ نهائي من ٣ أسئلة متنوعة.
- شاشة بداية باسم اللاعب.
- شهادة إنجاز نهائية قابلة للطباعة.
- يعمل كـ PWA ويمكن نشره مباشرة على GitHub Pages.
- مؤثرات صوتية بسيطة فقط، بدون موسيقى.

## النشر على GitHub Pages
ارفع **كل محتويات هذا المجلد** إلى جذر المستودع، وتأكد أن `index.html` في المستوى الأعلى، ثم فعّل GitHub Pages من Settings > Pages.
