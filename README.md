# مغامرة كنز القيمة المنزلية — V2.2

نسخة تفاعلية عربية للصف الثالث الابتدائي.

## أهم تعديل في V2.2
- حذف لوحة التعليمات الكبيرة من يسار اللعبة نهائيًا.
- حذف شريط «طريقة اللعب» أسفل اللعبة نهائيًا.
- اعتماد خلفية نظيفة بدون اللوحة الجانبية.
- إعادة ضبط أماكن السحب والضغط على الأبواب وبطاقات نماذج القيمة المنزلية.
- الإبقاء على التعليمات القصيرة داخل رسائل اللعبة المؤقتة فقط.
- جميع الأرقام الديناميكية بالأرقام العربية ٠١٢٣٤٥٦٧٨٩.
- المستويات: بناء العدد، الصيغة القياسية، الصيغة التحليلية، الصيغة اللفظية، تحدي الكنز النهائي.
- شهادة إنجاز نهائية قابلة للطباعة.
- بدون موسيقى؛ مؤثرات صوتية بسيطة يمكن إيقافها.
- تذييل: أ/ فاطمة هزازي — ملتقى التعليم التفاعلي — ملتقى معلمي ومعلمات الرياضيات.

## النشر على GitHub Pages
ارفع جميع الملفات والمجلدات الموجودة داخل هذا المجلد إلى جذر المستودع. إذا كان إصدار قديم مفتوحًا على الجهاز، حدّث الصفحة تحديثًا قويًا مرة واحدة لأن V2.2 يستخدم اسم Cache جديدًا.
