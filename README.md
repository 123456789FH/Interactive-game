# مغامرة كنز القيمة المنزلية — V2.5

## أهم إصلاح في هذا الإصدار
- عند فتح الرابط على الجوال **بالوضع العمودي** تظهر شاشة جميلة تطلب تدوير الجهاز أفقيًا بدل ظهور جزء صغير من اللعبة ومساحة زرقاء طويلة.
- عند تدوير الجوال **أفقيًا** تختفي شاشة التوجيه تلقائيًا وتملأ اللعبة أكبر مساحة ممكنة من الشاشة مع الحفاظ على نسبة 16:9 من دون قص.
- شاشة البداية أصبحت مضغوطة ومناسبة لارتفاع شاشة الهاتف في الوضع الأفقي، ويمكن تمريرها إذا كان المتصفح يعرض شريط أدوات كبيرًا.
- دعم Safe Area للآيفون والآيباد.
- أضيف `orientation: landscape` إلى ملف PWA للأجهزة التي تدعمه.
- تحديث اسم cache إلى V2.5 حتى لا تبقى نسخة V2.4 القديمة بعد الرفع إلى GitHub Pages.

## الرفع
استبدل ملفات المستودع كلها بمحتويات هذا المجلد، ثم انتظر GitHub Pages حتى يكتمل النشر. عند التجربة على الجوال افتح الرابط من جديد أو حدّث الصفحة مرة واحدة.
